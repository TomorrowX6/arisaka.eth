## 第六段：射频取证与图分析（34 关 / 38 应用）

- 34：真实 SigMF `cf32_le` 复数基带，未标注突发位置；明确为自定义 OFDM64 遥测 PHY，不冒称 IEEE 802.11。长训练、循环前缀、整数 / 小数频偏、逐突发 I/Q 共轭、短多径深衰落与噪声，必须做同步、信道估计及导频相位跟踪。
- BPSK 保护头、64-QAM 数据、K=7 卷积码、3/4 打孔、两级交织、未知非零扰码状态、SERVICE / padding / tail 和双 CRC。纠错结果仍需 Ed25519 认证和精确 uint64 提交语义，不能把更高 epoch 的伪签名或 prepare 选为当前材料。
- 独立维护端使用 radix-2 FFT、软 LLR / Viterbi；发射器用直接逆 DFT，二者不共享调制、同步、映射或校验实现。固定码脉冲响应、CRC 检查值、直接 DFT oracle、穷举最大似然 oracle 与多种子恢复交叉验证。32 个自动种子覆盖所有整数频偏 / 两种 I/Q 方向，另有 64 个随机种子实验全部恢复；软解码确实修正数千个硬判决错误，不只是解读干净比特。
- 图分析台：有向 / 无向多重图 JSON、RFC4180 CSV；精确整数边权、孤立点 / 平行边 / 自环、SCC / 凝聚图 / 拓扑与环见证、BFS、DAG / Dijkstra / Bellman–Ford 最短路、Lengauer–Tarjan 支配树与可选 SSA 支配边界。负环只影响可达后继，不把其他有限路径一起作废。
- 图算法用独立顶点删除 / Floyd–Warshall oracle 检验不可约流图、支配边界和负环；深链避免递归栈限制。4 MiB / 4096 节点 / 16384 边，20 秒 Worker 可取消，昂贵步骤另有 800 万步上限，超限不返回部分解。
