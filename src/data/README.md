# Roro 动漫语料

`anime-quotes.json` 包含 **1,490 条去重短语录**，由 `scripts/sync-anime-quotes.mjs` 从 [Hitokoto sentences-bundle](https://github.com/hitokoto-osc/sentences-bundle) 抓取并筛选。源版本固定为 `e92f39455e28fb893651ff67c938ee1465f0aa21`，保留每条的来源 ID、原始作品署名及可用的角色署名。

当前包含动画 1,345 条、漫画 95 条、匹配偏好作品的视觉小说及游戏 50 条。仅保留有出处、正文 4–60 字符、带出处显示不超过 100 字符的短句；剔除空来源、链接和标记，按规范化文本去重，不截断原句。社区署名按原样保留，不代表已逐条对照官方字幕核实。

`anime-quote-preferences.json` 按作品及别名配置偏好。标签是本站的选句偏好，包含有百合元素的日常作品；“神作”是本站选取的经典作品范围。标签允许重叠，558 条语录至少命中一个偏好：

| 偏好 | 语录数 | 附加抽取权重 |
| --- | ---: | ---: |
| 催泪 | 227 | 9 |
| 百合 | 38 | 8 |
| 恋爱 | 314 | 7 |
| 日常 | 59 | 6 |
| 治愈 | 92 | 6 |
| 神作 | 256 | 4 |

每条基础权重为 1，再加上匹配标签的权重。浏览器从完整语料中加权选取 39 条不同语录，本轮抽完后补充下一轮，并排除上一轮的 39 条。只持久保存 ID 和抽取进度，不重复保存整份语料；非文章页面共用这一轮，每 10 秒更换一句。公开文章页使用 Worker 生成并缓存的 39 条 AI 文章话题，独立于此动漫语料。

在仓库根目录重新生成：

```powershell
pnpm quotes:sync
pnpm test
```

更新上游时修改同步脚本里的固定 revision，再运行同步和测试。`anime-quotes.provenance.json` 记录原始文件链接、版本、数量和筛选方式，`anime-quotes.json` 的版本由内容哈希生成，更新语料后浏览器会自动重建不兼容的旧缓存。

上游语料与修改后的选集采用 **AGPL-3.0-only**；完整许可证随 `anime-quotes.LICENSE` 提供，同步脚本标有相同 SPDX 许可。发布时保留来源、许可证及修改后的语料和生成脚本。
