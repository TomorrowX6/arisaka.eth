**和弦**
| 和弦       | 公式            | C为根音       |
| -------- | ------------- | ---------- |
| Major 大三 | `1 3 5`       | C E G      |
| minor 小三 | `1 ♭3 5`      | C E♭ G     |
| dim 减三   | `1 ♭3 ♭5`     | C E♭ G♭    |
| aug 增三   | `1 3 ♯5`      | C E G♯     |
| maj7 大七  | `1 3 5 7`     | C E G B    |
| m7 小七    | `1 ♭3 5 ♭7`   | C E♭ G B♭  |
| 7 属七     | `1 3 5 ♭7`    | C E G B♭   |

**常用和弦进行**
| 级数     | 和弦         | 用途/感觉    |
| ------ | ---------- | -------- |
| `4536` | F-G-Em-Am  | 日系常用、流动感 |
| `1564` | C-G-Am-F   | 流行、开阔    |
| `6415` | Am-F-C-G   | 感伤、循环感强  |
| `6451` | Am-F-G-C   | 感伤后回家    |
| `251`  | Dm-G-C     | 经典解决     |
| `451`  | F-G-C      | 直接回家     |
| `6251` | Am-Dm-G-C  | 很顺的回归    |
| `3625` | Em-Am-Dm-G | 强循环感     |

旋律不跑调情况下自由发挥啦，毕竟本人也是萌新
